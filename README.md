# CallPilot.AI — FlexCare AI Voice Assistant

**Clinic:** FlexCare Physiotherapy & Sports Rehabilitation

An AI-powered voice assistant designed to support clinic communication and physiotherapy appointment scheduling.

[Live Demo](https://flexcare-ai-calling-assistant.vercel.app/) · [GitHub Repository](https://github.com/MahamYasir-ai/flexcare-ai-calling-assistant)

---

## Overview

CallPilot.AI is a healthcare-focused AI voice assistant developed for FlexCare Physiotherapy & Sports Rehabilitation. The project explores how conversational AI can support routine clinic communication and appointment coordination through voice-based interactions.

The application combines a web interface with an AI voice-agent integration to demonstrate a practical use case for AI-powered calling in a physiotherapy setting.

## Key Features

- **AI Voice Assistant:** Enables conversational voice interactions through an integrated voice-agent workflow.
- **Appointment Scheduling:** Designed around physiotherapy appointment coordination.
- **Clinic-Focused Communication:** Tailored to the communication needs of a physiotherapy and sports rehabilitation clinic.
- **Voice-Agent Integration:** Uses OmniDimension to power the voice-agent experience.
- **Web Application:** Provides a dedicated interface for accessing the project.
- **Live Deployment:** Hosted on Vercel for browser-based access.

## Technology Stack

| Technology | Purpose |
|---|---|
| OmniDimension | AI voice-agent integration |
| Web technologies | Application interface |
| Vercel | Deployment and hosting |

## How It Works

1. A user accesses the CallPilot.AI web application.
2. The voice-agent workflow supports conversational interaction.
3. The assistant is designed to help with clinic-related communication and appointment coordination.
4. The integrated voice-agent platform handles the voice interaction according to its configured workflow.

The exact calling behavior and available actions depend on the current agent configuration and application implementation.

## Project Objectives

- Explore practical applications of conversational AI in healthcare.
- Integrate a voice agent into a dedicated web application.
- Demonstrate AI-assisted appointment coordination for physiotherapy services.
- Develop practical experience with AI tools, web applications, and voice-agent integration.
